# FINAL DOMAIN ARCHITECTURE

## Routing & SSL
- **Canonical Domain**: `onnesha.app`
- **Subdomains**: 
  - `app.onnesha.app` (Hospital Admin/Staff Portal)
  - `www.onnesha.app` (Public Website)
  - `api.onnesha.app` (Backend APIs)
- **SSL**: Managed via Cloudflare Universal SSL for all domains with strict HTTPS enforcement.
