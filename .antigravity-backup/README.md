## How to Restore After a Fresh Windows Install or on Any PC

### Method 1: 1-Click Double-Click (Easiest)
Simply double-click `restore-antigravity.bat`.

### Method 2: PowerShell
Open PowerShell in this folder and run:
```powershell
powershell -ExecutionPolicy Bypass -File .\restore-antigravity.ps1
```
